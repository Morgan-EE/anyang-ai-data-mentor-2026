# AI·데이터 현직자 멘토링 대시보드

2026년 10월 22일(목) 안양시 청년 일자리박람회(안양아트센터) AI·데이터 멘토링 현장에서 **멘토가 참고하는 개인용 상담 도구**입니다.

- 정적 웹사이트 (HTML/CSS/JavaScript만 사용, 외부 라이브러리·서버·DB·AI API 없음)
- 로그인·개인정보 수집·외부 전송 없음
- GitHub Pages 하위 경로(`/anyang-ai-data-mentor-2026/`)에서 동작하도록 모든 경로를 상대 경로로 작성

> ⚠️ GitHub Pages 무료 배포는 **URL을 아는 누구나 접근할 수 있습니다.** `noindex`는 검색 노출을 줄일 뿐 접근 제한이 아닙니다. 공개되어도 괜찮은 내용만 넣으세요.

## 기능

| 메뉴 | 내용 |
|---|---|
| 홈 / 상담 시작 | 15·20분 타이머(단계 표시·단계 이동), 자기소개 30초/1분, 시작 질문, 직무 바로가기, 그룹 진행 팁, 실무 이야기, 마무리 멘트 |
| 진로를 모르겠어요 | 질문 5개 → 먼저 탐색할 직무 + 함께 탐색할 직무, 추천 근거, 첫 학습, 일주일 과제, 30초 멘트. Q1·Q2 모두 '모르겠어요'면 입문 체험 A·B·C |
| 직무 가이드 ×4 | AI 서비스 기획자 · 프롬프트 엔지니어 · 데이터 분석가 · LLM 응용 개발자 (정의, 업무 사례, 역량, 수준별 학습, 로드맵, 포트폴리오, 자격증 활용도·한계, 교육·채용공고, 면접, 실수, Q&A, 피드백 멘트) |
| 학생 수준별 조언 | 특성화고 · 대학생 · 비전공 · 졸업예정 · 취준생 · 프로젝트 경험자 · 입문자 |
| 예상 질문 FAQ | 50개 (현장 답변 + 추가 설명), 부분 검색 |
| 추천 학습 자료 / 출처 | 2026-10-21 확인한 공식 링크, 채용공고 관찰 기록, 정보 구분 표시 |

상단 검색창(`/` 키)은 FAQ·직무·자료 전체를 검색합니다.

## 진로 탐색 추천 로직 (`data/explore.js`)

- Q1(흥미)·Q2(업무 방식): 선택한 직무 **+2점**
- Q3(경험): AI 도구 → 프롬프트 +1, 엑셀 → 분석가 +1, 코딩 → 개발자 +1
- Q4(목표): 점수 영향 없음, 결과에서 연결할 가이드 섹션만 결정
- Q5(시간): 점수 영향 없음, 실천 과제 크기만 결정
- 동점: Q2 응답 직무 → Q1 응답 직무 → 기획자·분석가·프롬프트·개발자
- 2순위 점수가 0이면 인접 직무를 '함께 탐색'으로 표시
- Q1·Q2 모두 모르겠음 → 직무 추천 없이 체험 A·B·C 제안

## 행사 직전 내용 수정

`data/` 폴더의 파일만 고치면 됩니다. (메모장·VS Code 등으로 열어 따옴표 안 문장만 수정)

| 파일 | 내용 |
|---|---|
| `data/mentor.js` | 자기소개, 상담 흐름, 시작 질문, 마무리 멘트 |
| `data/jobs.js` | 4개 직무 가이드 |
| `data/explore.js` | 진로 탐색 질문·점수·결과 문구 |
| `data/levels.js` | 수준별 조언, 교육과정 선택 기준 |
| `data/faq.js` | 예상 질문·답변 |
| `data/resources.js` | 자료 링크, 출처, 조사 한계 |

수정 후 단일 파일 버전을 다시 만들려면: `python3 tools/build_single.py`

## 오프라인 사용 (행사장 인터넷이 불안정할 때)

1. **가장 확실한 방법:** `mentor-offline.html` 한 파일을 노트북에 저장 → 더블클릭 (인터넷 불필요)
2. 폴더 전체를 받아 `index.html`을 더블클릭해도 동작합니다.
3. GitHub Pages 주소로 한 번 접속해 두면 브라우저가 파일을 캐시해 두어 연결이 끊겨도 다시 열 수 있습니다(서비스 워커). 단, 이 캐시는 보조 수단이니 1번을 함께 준비하세요.
